## Overview

### The Challenge

Users should be able to:

- View the optimal layout for the component depending on their device's screen size
- See the card centered on the page with proper spacing, rounded corners, and shadow

### Style Guide

- Font size: 15px
- Font family: [Outfit](https://fonts.google.com/specimen/Outfit)

Colors:

| | Hex/HSL |
|---|---|
| White | `hsl(0, 0%, 100%)` |
| Light gray | `hsl(212, 45%, 89%)` |
| Grayish blue | `hsl(220, 15%, 55%)` |
| Dark blue | `hsl(218, 44%, 22%)` |

- Structuring a simple project with clean HTML and CSS
- Applying rounded corners, box-shadow, and centering elements
- Loading and using an external font from Google Fonts
- Using `max-width` and `margin: auto` to center a component on the page
